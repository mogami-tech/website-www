About us.

At Mogami, we believe the future of the Internet depends on seamless, frictionless value exchange.

That’s why we are building the x402 stack - SDKs, servers, console, and examples to get you from zero to production in minutes. Whether you’re monetizing APIs, enabling machine-to-machine commerce, or building AI agents, Mogami gives you the building blocks for fast, secure, and reliable payment flows.


Our mission:

Simplify x402 Adoption with our complete stack.

Enable Frictionless Monetization with our Java client and server SDKs.

Foster an Open x402 Ecosystem with core components released as open source.

Java client SDK

Use x402 payments into your apps: fetch requirements, sign, and send transactions.

Java server SDK

Protect your APIs with pay-per-call logic using a single Spring Boot annotation.

Facilitator server

Run your own payment gateway as a Docker image, or use ours online to verify and settle x402 transactions instantly.

x402 console

Trace every payment end-to-end with a live, time-ordered feed of server and facilitator messages.

Examples

Learn x402 through real-world demos of paywalled endpoints and instant payment flows.

Playground

Test x402 for real: call our example REST API, protected by x402, directly from your own client code.
